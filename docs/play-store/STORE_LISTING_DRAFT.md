# Store listing draft

**App name:** SM HRMS

**Short description:** Attendance, leave, tasks and field workforce management for organizations.

**Full description:**
SM HRMS helps organizations manage everyday workforce operations from one mobile-friendly workspace. Employees can access attendance, leave, assigned work and permitted field workflows, while authorized managers can use the modules enabled for their organization.

Core capabilities can include attendance IN/OUT, leave management, task/delegation workflows, field visits, duty-time field tracking, notifications, employee directory and HR administration. Available features depend on the organization’s plan and permissions.

SM HRMS is designed for authorized workplace use. Location and camera access are requested only for features that need them and remain subject to organization settings and user permissions.
